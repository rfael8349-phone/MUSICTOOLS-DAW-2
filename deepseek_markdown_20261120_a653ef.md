# MUSICTOOL DAW

DAW en el navegador para iPhone. Funciona en GitHub Pages, sin instalar nada.

## Cómo usar
1. Abre la URL de GitHub Pages en Safari.
2. Toca "+A" (audio) o "+M" (MIDI) para añadir una pista.
3. Toca "Importar" para subir audio, o toca doble en el timeline para añadir notas MIDI.
4. "Guardar" descarga el proyecto como .json — súbelo a Google Drive o iCloud.
5. "Cargar" restaura un .json guardado.
6. "Exportar WAV" descarga la mezcla.

## Notas iOS
- El sonido requiere tocar el botón ▶ (política de Safari).
- Los proyectos se guardan como archivos .json que puedes subir a Google Drive/iCloud.
